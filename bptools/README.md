# BPTOOLS

Плагін для AutoCAD 2024 і новіших. Вкладка **«Креслення»** ставить написи креслень джгутів в одному стилі: позиційні номери (`BPPOS`), номери контактів (`BPPIN`), кольори проводів (`BPWIRE`), назви роз'ємів (`BPNAME`), написи «Вигляд з …» (`BPVIEW`) і підписи рисунків (`BPFIG`). `BPPART` вставляє вигляд роз'єму з бібліотеки (з номерами контактів), `BPCENTER` центрує тексти між об'єктами, `BPSTYLE` дає вже набраним текстам стиль потрібного напису, `BPNEW` відкриває нове креслення з шаблону, а дві кнопки вирівнюють тексти й виноски командами самого AutoCAD. Номери позицій і рисунків рахуються в межах марки, яку знає [PDFALL](../pdfall/README.md).

**Покрокова інструкція** — файл `guide.html` у zip BPTOOLS, а після встановлення — **Інструкція BPTOOLS** у меню Пуск.

## Коротко

1. Закрийте AutoCAD.
2. Меню Пуск → **Оновити плагіни AutoCAD** → BPTOOLS → Enter, або завантажте `BPTOOLS-<версія>.zip` з [випусків](https://github.com/not-oleksii/autocad-plugins/releases), розпакуйте й двічі клацніть `install.bat`.
3. Запустіть AutoCAD і відкрийте вкладку **«Креслення»**.

Оновлення: меню Пуск → **Оновити плагіни AutoCAD**. Видалення: `uninstall.bat` з того самого zip. Що змінилося: [CHANGELOG.md](CHANGELOG.md).

Для розробників: [DEVELOPING.md](DEVELOPING.md) (англійською).
